Pixels and events
  • Meta Pixel + Conversions API through GoHighLevel (Settings → Integrations). Events: ViewContent on landing, AddToCart on sales page CTA, InitiateCheckout, Purchase with value.
  • TikTok Pixel: ViewContent, AddToCart, CompletePayment.
  • Custom event VideoWatched75 fired from the landing video player (already wired in landing/index.html).
UTM convention
  • utm_source=meta|tiktok · utm_medium=paid · utm_campaign=tof|mof|bof|rtg|ret · utm_content=V1|S-A|C-1…
  • GHL: map utm_content to a contact field so the Day-7 email can reference the ad they came from.

Launch calendar (first 4 weeks)

Week 0 · build — Import landing, sales, checkout and thank-you pages into GHL. Install pixels. Upload 12 stills and the 5 cut videos. Create audiences (they populate from day 1).
Week 1 · $50/day, TOF only — 1 CBO campaign, 2 ad sets (Broad, Interests), 5 ads each. Judge nothing before 50 clicks per ad. Kill any ad above $1.10 CPC or below 1.5% CTR after 1,500 impressions.
Week 2 · add MOF + RTG — Turn on MOF (15%) and cart retargeting (10%) once 300 site visitors exist. Start the SMS cart sequence. Duplicate the winning TOF ad into TikTok Spark.
Week 3 · BOF + first scale — Turn on BOF close. If blended CPA ≤ $22 for 7 days, raise daily budget 20%. Refresh one TOF hook (use hooks 9, 13, 18).
Week 4 · read + decide — Build LAL 1% from buyers if ≥100 purchases. Launch retention email. Move to the Scale scenario if ROAS ≥ 2.2× and refund rate < 5%.

What stays out of this plan, on purpose

Larger products

Lockboxes, routers, bundles. Nothing here advertises them. If a parent asks, the reply is: start with the disc.

Claims we never make

Reading messages, tracking location, “100% unbreakable”. Pausa blocks apps on a schedule and reports time. That is the honest, defensible claim.

Discounting

No coupon codes in month 1. The Pack Familiar is the only price lever; it protects margin and raises AOV.
